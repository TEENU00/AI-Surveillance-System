# AI Surveillance System

An AI-powered surveillance system for monitoring video feeds and detecting notable activity in real time.

## Features

- Real-time video monitoring
- AI-based object and activity detection
- Alerts for configurable events
- Support for recorded or live camera feeds

## Getting Started

### Prerequisites

- Python 3.9 or later
- A compatible camera or video source
- Required project dependencies

### Installation

```bash
git clone <repository-url>
cd ai-surveillance-system
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```

Configure camera sources, detection settings, and alert destinations according to the project configuration.
